# 화면설계서

**프로젝트명**: 티업링크 백오피스 재구축
**작성일**: 2026-10-28
**버전**: v1.0
**입력**: [정보구조도](정보구조도.md), [기능명세서](기능명세서.md)
**플랫폼**: PC 어드민 (1280px 이상 최적, 폰 360px에서 업무 처리 가능)

> 이 문서는 **패턴 우선**으로 작성합니다. 2장의 공통 레이아웃과 3장의 화면 패턴(목록·폼·상세)을 먼저 정의하고, 4장의 개별 화면은 패턴에서 달라지는 점(컬럼·필터·섹션·탭·작업)만 적습니다. 재구축의 1순위 문제가 "화면마다 제각각"이었으므로, 개별 화면이 패턴을 벗어나려면 이 문서를 먼저 고칩니다.

## 3. 화면 패턴

### 3.1 목록 패턴 (PTN-LIST)

```
+--------------------------------------------------------------------------+
| 클럽                                                [CSV 내보내기] [+ 등록] |
+--------------------------------------------------------------------------+
| [전체 120] [활성 112] [비활성 8]                                 상태 탭   |
| [ 클럽명·설명 검색        ] [유형 v] [지역 v] [기간 ~ ]          FilterBar |
| 적용: (유형: 정기 x) (지역: 서울 x)  모두 해제                    필터 칩   |
+--------------------------------------------------------------------------+
| [ ] | 클럽명 ^   | 유형 | 지역  | 리더   | 멤버 | 대기 | 상태 | 생성일 v  |
|-----+-----------+------+-------+--------+------+------+------+-----------|
| [ ] | 강남 골프회 | 정기 | 서울  | 김*수  |  24  |  3   | 활성 | 2026-10-01 |
| [ ] | ...       |      |       |        |      |      |      |           |
+--------------------------------------------------------------------------+
| 총 120건                       20 v  < 1 2 3 4 5 6 >                     |
+--------------------------------------------------------------------------+
```

| 요소 | 규칙 |
|------|------|
| 상태 탭 | 도메인에 상태 축이 있으면 사용. 탭별 건수 = 서버 total. URL `status` |
| FilterBar | 텍스트 검색(300ms) → select(즉시) → 기간 순서. 4개 초과 시 "필터 더보기" |
| 필터 칩 | 기본값이 아닌 필터만 칩으로 |
| 컬럼 | 첫 컬럼 = 식별 컬럼(이름·제목, 링크). 상태는 `StatusBadge`. 날짜 `YYYY-MM-DD`, 일시 `YYYY-MM-DD HH:mm`. 금액 우측 정렬 `1,000원`. 개인정보는 `formatPII` |
| 번호 컬럼 | **두지 않음** (기존 역순/정순 혼재 문제 제거) |
| 정렬 | 정렬 가능 컬럼만 헤더에 화살표. 4장 각 화면에 명시 |
| 행 작업 | 최대 2개 버튼 + 나머지는 `...` 메뉴. 파괴적 작업은 메뉴 안 |
| 선택 | 일괄 작업이 있는 화면만 체크박스 |
| 페이지 | 하단: 총 건수 / 크기 [20·50·100] / 페이지 번호 |

**상태별 화면**

| 상태 | 조건 | 표시 |
|------|------|------|
| 로딩(최초) | 데이터 없음 + 요청 중 | 테이블 스켈레톤 10행 |
| 로딩(재조회) | 이전 데이터 있음 | 이전 데이터 유지 + 상단 얇은 진행 바 |
| 빈 상태 | total 0, 필터 없음 | 아이콘 + "아직 {대상}이 없습니다" + [등록] |
| 결과 없음 | total 0, 필터 있음 | "조건에 맞는 결과가 없습니다" + [필터 해제] |
| 에러 | 요청 실패 | 메시지 + [다시 시도] |

| 등록/수정 | **같은 컴포넌트**. 제목·버튼 문구만 다름 |

## 4. 화면 상세

각 화면은 해당 패턴을 따르며, 아래는 화면별 정의입니다. 정렬 열의 컬럼만 정렬 가능합니다.

### 4.1 인증
