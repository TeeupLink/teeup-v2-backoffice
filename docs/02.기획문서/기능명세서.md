> **표기**

> - API 열의 경로는 `/api/v1/admin` 생략. `(신설)`은 backend 이슈에서 새로 만드는 엔드포인트, `(보강)`은 기존 엔드포인트의 파라미터·응답 정규화가 필요한 것

## 0. 공통 규칙 (모든 기능에 적용)

| 규칙 | 내용 |
|------|------|
| 목록 요청 | `page`(1-base), `size`(20·50·100, 기본 20), `sort`(`필드` 또는 `-필드`), `q`, 필터 키 — URL 쿼리와 동일 이름 |
| 목록 응답 | `{ items: T[], total: number, page: number, size: number }` 단일 envelope. 기존 9종은 BE#46에서 정규화, 정규화 전 엔드포인트는 프론트 어댑터 1곳에서 변환 |
| 일괄 요청 | `POST /x/bulk` `{ ids: number[], action: string, reason?: string }` → `{ succeeded: number[], failed: { id, message }[] }` |
| 에러 응답 | `{ detail: string \| { field, message }[] }` 우선, `message` 폴백. 프론트 추출 함수 1개 |
| 인증 | `Authorization: Bearer {jwt}`, 변경 요청(POST·PUT·PATCH·DELETE)은 직전에 `/auth/csrf-token`을 받아 `X-CSRF-Token` 첨부 |
| 권한 | BE `require_roles`가 최종 판단. FE는 라우트 가드·메뉴 숨김으로 UX 보조 |
| 개인정보 표시 | 이름·전화·이메일은 `formatPII()`를 거침 (마스킹 모드 F-131) |

## 2. 기능 상세

### 2.1 공통

#### F-001. 공통 목록 (DataTable + URL 상태)

| 항목 | 내용 |
|------|------|
| 설명 | 모든 목록 화면이 쓰는 단일 테이블. 컬럼 정의·데이터 조회 함수·필터 정의만 넘기면 검색·필터·정렬·페이징·선택·상태 탭이 동작 |
| 입력 | 컬럼 정의(TanStack Table `ColumnDef`, `enableSorting`), 필터 정의(`text`/`select`/`dateRange`/`tabs`), 조회 함수 `(query) => Promise<Page<T>>`, 행 클릭 경로 |
| 처리 | ① URL 쿼리 파싱 → 쿼리 객체(zod로 검증, 잘못된 값은 기본값) ② TanStack Query 키 = 쿼리 객체 ③ 텍스트 필터 300ms 디바운스, select·tabs 즉시 반영 ④ 필터 변경 시 `page=1` 리셋 ⑤ `replace`(입력 중)/`push`(확정) 구분으로 뒤로가기 동작 보장 ⑥ 이전 데이터 유지(`placeholderData`)로 깜빡임 방지 |
| 출력 | 테이블, 적용 필터 칩(개별 X·전체 해제), 상태 탭 건수 배지, 페이지네이션(총 건수·크기 선택), 모바일에서 가로 스크롤 |
| 예외 처리 | 조회 실패 → 공통 에러 + 재시도 버튼 / 결과 0건 → 필터 적용 여부에 따라 "결과 없음 · 필터 해제" 또는 "데이터 없음" / 존재하지 않는 페이지 → 마지막 페이지로 보정 |
| 관련 화면 | 모든 목록 SCR |
| 관련 API | 각 목록 API (공통 규칙의 목록 요청·응답) |

### 2.2 인증·레이아웃

#### F-010. 로그인·로그아웃

| 항목 | 내용 |
|------|------|
| 입력 | 이메일, 비밀번호 |
| 처리 | CSRF 발급 → `POST /login` → 토큰 저장(localStorage `teeup_admin_token`) → `GET /me` → 복귀 경로 또는 `/dashboard` |

| 관련 API | `/auth/csrf-token`, `/login`, `/logout`, `/me` |

#### F-011. HTTP 클라이언트

| 항목 | 내용 |
|------|------|
| 설명 | 단일 fetch 래퍼. 기존 4종 클라이언트 대체 |
| 처리 | baseURL = 개발 `/api/v1`(Vite proxy) · 운영 `/api/v1`(nginx), JSON 직렬화, 토큰 주입, 변경 메서드에 CSRF 자동 발급·첨부, 응답 envelope 어댑터, 에러를 `ApiError{status, message, fields}`로 변환 |
| 예외 처리 | CSRF 403(토큰 만료) → 1회 재발급 후 재시도 / 네트워크 오류 → `ApiError(status 0)` |

#### F-012. 세션 만료 처리

| 항목 | 내용 |
