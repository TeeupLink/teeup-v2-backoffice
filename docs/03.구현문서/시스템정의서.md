# 시스템 정의서

> 시스템의 기술 스택, 모듈 구성, 인터페이스 규약을 정의한다.

## 기술 스택

> V0.2 표준 스택: `React + Vite + Tailwind CSS / FastAPI / PostgreSQL(Supabase) / Cloud Run`
> 프로젝트별로 변경 시 PRD.md의 기술 스택 항목과 본 표를 함께 갱신하세요.
>
> **런타임 버전을 기록하는 곳은 여기입니다.** Python·Node 버전은 프레임워크가 고정하지 않으며,
> 초기 세팅에서 확정한 실제 값을 아래 "버전" 칸에 적습니다 (`.python-version` / `.nvmrc`와 일치시킬 것).

| 영역 | 기술 | 버전 | 비고 |
|------|------|------|------|
| Frontend | **React + Vite + TypeScript + Tailwind CSS** | [Node 버전] | V0.2 표준 (SPA) |
| Backend | **FastAPI (Python)** | [Python 버전] | V0.2 표준 |
| Database | **PostgreSQL (Supabase)** | [버전] | V0.2 표준 |
| Auth / Storage | **Supabase Auth / Storage** | - | V0.2 표준 (자체 JWT 미발급) |
| Deploy | **Google Cloud Run** | - | V0.2 표준 (web·api 별도 서비스) |
| CI/CD | GitHub Actions → `gcloud run deploy` | - | 표준 |
| 운영 알림 | Discord Incoming Webhook | - | 표준 (용도별 채널 분리) |
| Cache | [예: Redis] | [버전] | 선택 |
