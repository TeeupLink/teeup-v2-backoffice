# 디자인 스타일 가이드 (Design Style Guide)

**프로젝트명**: 티업링크 백오피스 재구축
**작성일**: 2026-10-28
**버전**: v1.0
**입력**: [서비스기획서](../02.기획문서/서비스기획서.md), [화면설계서](../02.기획문서/화면설계서.md), shortcrew 백오피스 (`shortcrew-main/app/admin/templates/layout.html`, `_admin_tailwind_config.html`)

> 구조·치수·클래스 패턴은 shortcrew 백오피스를 그대로 가져오고, 색만 티업링크 브랜드(그린 #4CAF50, 앰버 #FFC107)로 바꿉니다. shortcrew 폴더는 통합 후 삭제할 예정이므로 필요한 값은 모두 이 문서에 옮겨 적었습니다.

---

## 1. 디자인 원칙

1. **처리 속도 우선**: 운영자가 하루에 여러 번 반복하는 작업(승인·답변·점수 입력)은 클릭 수와 시선 이동을 줄이는 쪽으로 결정합니다.
2. **예외 없는 일관성**: 같은 종류의 정보는 같은 컴포넌트·같은 위치·같은 색입니다. 화면별 커스텀 스타일을 만들지 않습니다.
3. **정보 밀도**: 데스크톱 기준 한 화면에 목록 20행이 스크롤 없이 보이도록 행 높이·여백을 잡습니다. 장식보다 데이터.
4. **상태는 색 + 텍스트**: 상태를 색만으로 구분하지 않고 항상 라벨을 함께 씁니다(색각 이상·흑백 인쇄 대응).

## 2. 글로벌 레이아웃 (shortcrew 구조)

### 2.1 레이아웃 구조

```
+------------+----------------------------------------------+
|            |  Header (64px, 흰색, 하단 보더)                 |
|  Sidebar   +----------------------------------------------+
|  (240px)   |                                              |
|  다크       |  Main (slate-100 배경, 패딩 24px)              |
|            |  콘텐츠 최대 폭 1600px                          |
|            |                                              |
+------------+----------------------------------------------+
```

| 영역 | 크기 | 배경 | shortcrew 원본 클래스 |
|------|------|------|----------------------|
| 루트 | 100vh, overflow hidden | `bg-slate-100` | `h-screen overflow-hidden bg-slate-100 font-sans text-slate-900 antialiased` |
| 사이드바 (펼침) | `w-60` (240px) | `surface-card` #1E1E1E | `fixed … w-60 … bg-surface-card shadow-xl transition-[width,transform] duration-300` |
| 사이드바 (접힘) | `w-[4.25rem]` (68px) | 동일 | `lg:data-[collapsed=true]:w-[4.25rem]` |
| 사이드바 헤더 | `h-16` (64px) | 하단 `border-white/10` | 로고 32px `rounded-lg ring-1 ring-white/20` |
| 헤더 | `h-16` (64px) | `bg-white`, `border-b border-slate-200` | |
| 본문 | fluid, 패딩 `p-6` (모바일 `p-4`) | `bg-slate-100` | |

### 2.2 사이드바 상세

| 요소 | 스타일 |
|------|--------|
| 섹션 라벨 | `px-3 mb-2 mt-5 text-[0.65rem] font-bold uppercase tracking-wider text-white/55` |
| 메뉴 항목 | `rounded-lg px-3 py-2 text-sm font-semibold text-white/90 hover:bg-white/10` |
| 메뉴 활성 | `bg-primary-500/25 ring-1 ring-primary-300/40` (shortcrew와 동일 패턴, 색만 그린) |
| 메뉴 아이콘 | 20px, `mr-3 text-primary-50` |
| 메뉴 배지 | 우측 `rounded-full bg-secondary-500 text-slate-900 text-[0.7rem] font-bold px-1.5` (업무 메뉴 대기 건수) |
| 접힘 툴팁 | `absolute left-full ml-2 rounded-md bg-slate-900 px-2 py-1 text-xs text-white shadow-lg` — 접힘 + hover일 때만 |
| 스크롤바 | 4px, thumb `#4b5563` |
| 모바일 오버레이 | `bg-slate-900/50`, 사이드바 `-translate-x-full` → `translate-x-0` |

### 2.3 그리드·스페이싱

| 항목 | 값 |
|------|-----|
| 기본 단위 | 4px (Tailwind 기본 스케일) |
| 카드 내부 패딩 | `p-5` (20px), 모바일 `p-4` |
| 카드 간격 | `gap-4` (16px) — 대시보드 그리드, 폼 섹션 |
| 폼 필드 간격 | `space-y-4` |
| 테이블 셀 | `px-4 py-2.5`, 행 높이 약 44px |
| 대시보드 카드 그리드 | `grid-cols-1 sm:grid-cols-2 xl:grid-cols-4` |

## 3. 컬러 시스템

### 3.1 브랜드 컬러

Tailwind 토큰 이름은 shortcrew와 같게 `primary`·`surface`를 쓰고, shortcrew의 `brand.amber`는 `secondary`로 이름을 바꿉니다.

| 토큰 | 50 | 100 | 200 | 300 | 400 | **500** | 600 | 700 | 800 | 900 |
|------|----|-----|-----|-----|-----|---------|-----|-----|-----|-----|
| `primary` (그린) | #E8F5E9 | #C8E6C9 | #A5D6A7 | #81C784 | #66BB6A | **#4CAF50** | #43A047 | #388E3C | #2E7D32 | #1B5E20 |
| `secondary` (앰버) | #FFF8E1 | #FFECB3 | #FFE082 | #FFD54F | #FFCA28 | **#FFC107** | #FFB300 | #FFA000 | #FF8F00 | #FF6F00 |

**대비(WCAG AA 4.5:1) 때문에 정한 사용 규칙**

| 용도 | 토큰 | 대비 | 근거 |
|------|------|------|------|
| 주 버튼 배경 (흰 글자) | `primary-800` #2E7D32, hover `primary-900` | 5.13:1 | #4CAF50 위 흰 글자는 2.78:1로 미달 |
| 링크·강조 텍스트 (흰 배경) | `primary-800` | 5.13:1 | |
| 사이드바 활성·포커스 링·진행 바·체크박스 | `primary-500` | 비텍스트(3:1 기준) | 브랜드색이 가장 많이 보이는 곳 |
| 성공 배지 배경 | `primary-50` + 텍스트 `primary-800` | | |
| 앰버 | **배경으로만** 사용 + 텍스트 `slate-900` | 10.95:1 | 흰 배경 위 앰버 글자는 1.63:1로 사용 금지 |
| 앰버 용도 | 메뉴 배지, "중요" 배지, 마스킹 ON 표시, 경고 배너(`secondary-50` 배경 + `secondary-500` 좌측 보더) | | |

### 3.2 뉴트럴 (Tailwind `slate` 그대로)

| 용도 | 토큰 |
|------|------|
| 본문 배경 | `slate-100` |
| 카드·헤더 배경 | `white` |
| 보더 | `slate-200` (구분), `slate-300` (입력) |
| 본문 텍스트 | `slate-900` |
| 보조 텍스트 | `slate-500` (흰 배경 4.76:1) |
| 비활성 텍스트 | `slate-400` (정보 전달용으로 쓰지 않음) |
| 테이블 헤더 배경 | `slate-50` |
| 행 hover | `slate-50` / 선택 행 `primary-50` |

### 3.3 표면 (사이드바 다크)

| 토큰 | 값 | 용도 |
|------|----|------|
| `surface-base` | #121212 | (예비) |
| `surface-card` | #1E1E1E | 사이드바 배경 |
| `surface-muted` | #262626 | 사이드바 hover 대체 |
| `surface-border` | #2E2E2E | 사이드바 구분선 |

### 3.4 시맨틱 컬러

| 의미 | 배지 배경 / 텍스트 | 강조 텍스트·아이콘 | 사용 |
|------|-------------------|-------------------|------|
| success | `primary-50` / `primary-800` | `primary-800` | 활성, 승인, 완료, 결제 완료 |
| warning | `secondary-50` / `amber-800` | `amber-700` #B45309 | 대기, 검토중, 연체, 경과 24h |
| danger | `red-50` / `red-700` | `red-600` #DC2626 | 거절, 삭제, 실패, 취소, 경과 72h |
| info | `blue-50` / `blue-700` | `blue-600` #2563EB | 진행중, 처리중, 정보 |
| neutral | `slate-100` / `slate-700` | `slate-500` | 비활성, 종료, 초안, 지난 버전 |

### 3.5 상태 → 색 매핑 (`lib/status.ts` 단일 정의)

| 도메인 | success | warning | info | danger | neutral |
|--------|---------|---------|------|--------|---------|
| 회원 | ACTIVE | - | - | DELETED | DEACTIVATED |
| 클럽 | ACTIVE | - | - | - | INACTIVE |
| 가입신청 | 승인(이력) | PENDING | - | 거절(이력) | - |
| 모임 | COMPLETED | SCHEDULED | IN_PROGRESS | CANCELED | - |
| 문의 | RESOLVED·COMPLETED | PENDING·SUBMITTED | IN_PROGRESS | - | CLOSED |
| 신고 | RESOLVED | PENDING | REVIEWING | - | DISMISSED |
| 결제 | SUCCEEDED | PENDING | 부분취소(계산) | FAILED, 취소(계산) | - |
| 참가자 | CONFIRMED | PENDING, WAITING_LIST | - | CANCELED | - |
| 구독 | ACTIVE | PAST_DUE | - | - | CANCELED |
| 약관 | 게시중 | - | 초안 | - | 지난 버전 |
| 감사 결과 | SUCCESS | - | - | FAIL | - |

### 3.6 차트 팔레트

순서: `primary-500` #4CAF50 → `blue-500` #3B82F6 → `secondary-500` #FFC107 → `violet-500` #8B5CF6 → `slate-400` #94A3B8. 단일 계열 추이는 `primary-500` 하나만 씁니다. 그리드 선 `slate-200`, 축 텍스트 `slate-500` 12px.

## 6. 핵심 UI 컴포넌트

### 6.1 버튼

| 변형 | 스타일 | 용도 |
|------|--------|------|
| primary | `bg-primary-800 text-white hover:bg-primary-900` | 화면당 주 작업 1개 (저장·등록·승인) |
| secondary | `bg-white text-slate-700 ring-1 ring-slate-300 hover:bg-slate-50` | 보조 작업 (취소·내보내기·필터) |
| danger | `bg-red-600 text-white hover:bg-red-700` | 확인 다이얼로그 안의 삭제·거절 확정 |
| danger-ghost | `text-red-700 hover:bg-red-50` | 메뉴·행 안의 삭제 진입 |
| ghost | `text-slate-600 hover:bg-slate-100` | 아이콘 버튼, 툴바 |

공통: `h-9 px-3.5 rounded-lg text-sm font-medium`, 작은 크기 `h-8 px-3`, 포커스 `focus-visible:ring-2 ring-primary-500 ring-offset-2`, 로딩 시 스피너 + 비활성.

### 6.2 입력

| 상태 | 스타일 |
|------|--------|
| 기본 | `h-9 rounded-lg border border-slate-300 bg-white px-3 text-sm` |
| 포커스 | `border-primary-500 ring-2 ring-primary-500/20` |
| 에러 | `border-red-500` + 하단 `text-xs text-red-600` |
| 비활성 | `bg-slate-50 text-slate-500` |
| 라벨 | `text-sm font-medium text-slate-700`, 필수 `*` `text-red-600` |

### 6.3 카드

`rounded-xl bg-white shadow-sm ring-1 ring-slate-200`. 카드 제목 영역 `px-5 py-4 border-b border-slate-100`.

### 6.4 배지

`inline-flex items-center rounded-md px-2 py-0.5 text-xs font-medium` + 3.4 시맨틱 배경/텍스트. 역할 배지는 neutral, "중요"는 `bg-secondary-500 text-slate-900`.

### 6.5 데이터 테이블

| 요소 | 스타일 |
|------|--------|
| 컨테이너 | 카드 안, 가로 스크롤 `overflow-x-auto`, 첫 컬럼 `sticky left-0` |
| 헤더 | `bg-slate-50 text-xs font-medium text-slate-500`, 정렬 가능 컬럼 hover `text-slate-900` + 화살표 |
| 행 | `border-b border-slate-100`, hover `bg-slate-50`, 선택 `bg-primary-50` |
| 식별 컬럼 | `font-medium text-slate-900`, 링크 hover 밑줄 |
| 숫자 | 우측 정렬 `tabular-nums` |
| BulkActionBar | 하단 고정 `fixed bottom-4 left-1/2 -translate-x-1/2 rounded-xl bg-slate-900 text-white shadow-xl px-4 py-2.5` (사이드바 폭만큼 오프셋) |

### 6.6 모달·드로어

| 컴포넌트 | 스타일 |
|----------|--------|
| 오버레이 | `bg-slate-900/50` |
| 모달 | `max-w-lg` (폼 `max-w-2xl`), `rounded-xl bg-white shadow-xl`, 하단 버튼 우측 정렬 |
| 드로어 | 우측 `w-[480px]` (모바일 전체), 슬라이드 |
| Toast | 우하단, `rounded-lg bg-slate-900 text-white`, 성공 아이콘 `primary-400`, 실패 `red-400`, 4초 |

## 8. 반응형·접근성

### 8.1 브레이크포인트 (shortcrew 기준 유지)

| 이름 | 폭 | 레이아웃 |
|------|----|---------|
| 모바일 | < 1024px | 사이드바 드로어, 본문 `p-4`, 폼 1열 |
| 태블릿 (`tablet`/`lg`) | 1024 ~ 1279px | 사이드바 자동 접힘(68px) |
| 데스크톱 (`desktop`/`xl`) | ≥ 1280px | 사이드바 펼침(사용자 설정 유지) |

### 8.2 접근성 (WCAG 2.1 AA)

| 항목 | 기준 |
|------|------|
| 텍스트 대비 | 4.5:1 이상 (3.1 사용 규칙) |
| 포커스 | 모든 상호작용 요소 `focus-visible` 링 |
| 키보드 | 모달·드롭다운 포커스 트랩 (Radix), 테이블 행 링크 Tab 이동, 통합 검색 `/` |
| 스크린리더 | 아이콘 버튼 `aria-label`, 상태 배지 텍스트 포함, 정렬 헤더 `aria-sort` |
