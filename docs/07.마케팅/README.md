# 07.마케팅

> 영업·마케팅 트랙 확장 폴더입니다. Document Chaining 핵심 17단계에는 포함되지 않으며, 기획 산출물을 입력으로 파생됩니다.

## 용도
- 마케팅 전략, 퍼널 설계, 캠페인 기획, 채널 운영 계획, 성과 리포트 저장
- 입력 자료: `02.기획문서/마켓리서치.md`, `02.기획문서/서비스기획서.md`, `06.콘텐츠/`

## 산출물 예시
| 파일 | 설명 |
|------|------|
| 마케팅전략.md | STP·포지셔닝·채널 믹스 |
| 퍼널설계.md | 콘텐츠 -> 유입 -> 상담 -> 전환 퍼널 |
| 캠페인기획.md | 캠페인별 목표·예산·KPI |

> 핵심 산출물이 아니므로 NotebookLM 자동 등록 대상에서 제외합니다(필요 시 수동 등록).
