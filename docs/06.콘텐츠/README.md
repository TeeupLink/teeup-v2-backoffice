# 06.콘텐츠

> 영업·마케팅 트랙 확장 폴더입니다. Document Chaining 핵심 17단계에는 포함되지 않으며, 기획 산출물을 입력으로 파생됩니다.

## 용도
- 블로그/아티클, 쇼츠·영상 스크립트, 상세페이지 카피, FAQ, 뉴스레터 등 콘텐츠 자산 저장
- 입력 자료: `02.기획문서/서비스기획서.md`, `02.기획문서/마켓리서치.md`, `03.구현문서/디자인스타일가이드.md`

## 산출물 예시
| 파일 | 설명 |
|------|------|
| 블로그_콘텐츠캘린더.md | 키워드·주제·발행 일정 |
| 쇼츠_스크립트.md | 숏폼 영상 대본 |
| 상세페이지_카피.md | 랜딩/상세페이지 문구 |

> 핵심 산출물이 아니므로 NotebookLM 자동 등록 대상에서 제외합니다(필요 시 수동 등록).
