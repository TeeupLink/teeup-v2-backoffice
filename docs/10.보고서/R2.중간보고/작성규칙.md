# 중간보고 작성규칙

> 원본 규칙: `01.관리문서/중간보고서.md`, `CLAUDE.md`의 Document Chaining / Gate-Check Rules

## 기본 규칙

- **산출물 번호**: #14 (중간보고서)
- **전제조건**: #1 착수보고서 완료 + 기획 산출물 2개 이상 완료
- **파일명**: `중간보고서_YYYY-MM-DD.md` (날짜 = 보고 기준일)
- **데이터 소스**: 착수보고서(계획 대비 실적), WBS 진척률, GitHub Issues 현황, `.progress.md`

## 자동 생성

```
claude "착수보고서 계획 대비 실적을 비교하여 중간보고서를 작성해줘"
```

발행본은 `10.보고서/R2.중간보고/중간보고서_YYYY-MM-DD.md`로 저장합니다.
기존 발행본을 덮어쓰지 않고 누적합니다.

## 문서 구성

`템플릿.md`의 7개 섹션을 그대로 사용합니다.

| # | 섹션 |
|---|------|
| 1 | 프로젝트 현황 요약 |
| 2 | 일정 대비 진척 현황 (WBS 진척률 / 산출물 완성 현황 / GitHub Issues 현황) |
| 3 | 주요 성과 |
| 4 | 이슈 및 리스크 (현재 이슈 / 리스크 현황 — 착수보고서 대비) |
| 5 | 계획 대비 변경 사항 |
| 6 | 향후 계획 (잔여 작업 / 마일스톤) |
| 7 | 의사결정 요청 사항 |

## 출력 변환

발주처 제출본은 PDF로 변환합니다 (`doc-report` 또는 `pdf-report` 스킬).
변환 파일명에는 `_YYYYMMDD_HHMM` 타임스탬프를 붙입니다 (`CLAUDE.md` "산출물 HTML/PPTX 출력 파일명 규칙").
