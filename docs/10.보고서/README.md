# 10.보고서

보고서 **발행본**을 보관하는 폴더입니다.

## 01.관리문서와의 관계

| | `01.관리문서/` | `10.보고서/` (이 폴더) |
|---|---|---|
| 성격 | Document Chaining 산출물 (단일 파일) | 발행본 (날짜별 누적) |
| 파일명 | `주간보고서.md` | `주간보고서_2026-08-07.md` |
| Gate-Check | 대상 (#2·#14·#17) | 대상 아님 |

형식은 `01.관리문서/`의 산출물을 그대로 따릅니다. 이 폴더의 `템플릿.md`는 그 사본입니다.

## 폴더 구성

| 폴더 | 보고서 | 산출물 번호 | 전제조건 |
|------|--------|------------|----------|
| [R1.주간보고/](R1.주간보고/) | 주간보고서 | - | - |
| [R2.중간보고/](R2.중간보고/) | 중간보고서 | #14 | #1 완료 + 기획 산출물 2개 이상 |
| [R3.완료보고/](R3.완료보고/) | 완료보고서 | #17 | #16 완료 + 15개 이상 산출물 완료 |

각 폴더에 `템플릿.md`와 `작성규칙.md`가 있습니다.

## 공통

- 파일명은 `{산출물명}_{기준일}.md` 형식이며, 기존 발행본을 덮어쓰지 않고 누적합니다
- 발주처 제출본은 PDF로 변환합니다. 변환 파일명에는 `_YYYYMMDD_HHMM` 타임스탬프를 붙입니다 (`CLAUDE.md` "산출물 HTML/PPTX 출력 파일명 규칙")
