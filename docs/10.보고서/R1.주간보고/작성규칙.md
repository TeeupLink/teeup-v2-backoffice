# 주간보고 작성규칙

> 규칙의 원본은 `CLAUDE.md`의 "주간보고서 작성 규칙" 및 `01.관리문서/주간보고서.md`입니다.
> 이 문서는 그 규칙을 발행 폴더(`10.보고서/R1.주간보고/`) 기준으로 정리한 것입니다.

## 기본 규칙

- **보고 기간**: 요청일(D) 기준 **D-6 ~ D** (7일간)
- **파일명**: `주간보고서_YYYY-MM-DD.md` (D = 요청일)
- **데이터 소스**: GitHub Issues/Milestones API에서 7일 내 생성/완료 이슈 자동 수집

## 자동 생성

```
claude "이번 주 GitHub 커밋 로그와 이슈 상태를 분석하여 주간보고서를 작성해줘"
```

발행본은 `10.보고서/R1.주간보고/주간보고서_YYYY-MM-DD.md`로 저장합니다.
기존 발행본을 덮어쓰지 않고 누적합니다.

## 문서 구성

`템플릿.md`의 4개 섹션을 그대로 사용합니다.

| # | 섹션 | 항목 |
|---|------|------|
| 1 | 금주 실적 | 구분 / 계획 / 실적 / 달성률 / 비고 |
| 2 | 이슈 현황 | 이슈 / 상태(해결·진행중·미착수) / 영향도(고·중·저) / 대응 현황 |
| 3 | 차주 계획 | 구분 / 계획 / 담당 / 비고 |
| 4 | 리스크 업데이트 | 리스크 / 변동(신규·유지·해소) / 현재 상태 / 대응 방안 |

## 출력 변환

발주처 제출본은 PDF로 변환합니다 (`doc-report` 또는 `pdf-report` 스킬).
변환 파일명에는 `_YYYYMMDD_HHMM` 타임스탬프를 붙입니다 (`CLAUDE.md` "산출물 HTML/PPTX 출력 파일명 규칙").
