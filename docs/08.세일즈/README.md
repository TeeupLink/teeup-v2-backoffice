# 08.세일즈

> 영업·마케팅 트랙 확장 폴더입니다. Document Chaining 핵심 17단계에는 포함되지 않으며, 기획·구현 산출물을 입력으로 파생됩니다.

## 용도
- 세일즈 자료(피치덱·견적·세일즈 스크립트·고객 응대 Q&A·계약/SOW 초안) 저장
- `09.제안서/`와 연계: 제안서를 요약/시각화한 영업 자료를 이 폴더에 보관

## 산출물 예시
| 파일 | 설명 |
|------|------|
| 피치덱.md | 고객 미팅용 핵심 슬라이드 구성 |
| 견적서.md | 상세 견적·옵션별 금액 |
| 세일즈스크립트.md | 콜·미팅 대응 화법 |

> 핵심 산출물이 아니므로 NotebookLM 자동 등록 대상에서 제외합니다(필요 시 수동 등록).
